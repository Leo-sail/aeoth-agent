# Agent 协作团队 DSH 插件开发方案

## 一、项目概述

### 1.1 项目目标

将 Aeoth Agent 中的 Agent 协作团队功能改造为独立的 DSH 插件，使其可以被任何 DeepSeek Harness 项目安装和使用。

### 1.2 核心功能范围

本插件将包含以下功能模块：

1. **Agent Community（Agent 社区）**
   - Bot 创建与管理
   - 直接聊天（Direct Chat）
   - 群组聊天（Group Chat）
   - Bot 运行状态管理
   - 消息历史持久化

2. **Agent Team（Agent 团队）**
   - 团队创建与管理
   - 成员生成（Spawn Teammate）
   - 任务分配（Task Assignment）
   - 成员间消息传递
   - 任务依赖管理（Task DAG）

3. **UI 组件**
   - Agent 社区面板
   - 团队管理面板
   - Bot 配置界面
   - 运行状态可视化

### 1.3 技术栈

- **运行时**: Node.js >= 22.19.0 或 >= 24.0.0
- **包管理**: pnpm 11.7.0
- **框架**: Cordis（插件架构）
- **构建**: tsdown, TypeScript 6.0.3
- **UI**: Web Components（浏览器端）

## 三、核心包设计

### 3.1 agent-community 包

**功能职责**：
- Bot 身份管理
- 房间（Room）管理
- 消息路由与持久化
- Bot 运行调度
- 状态同步

**核心服务**：`AgentCommunityService`

**关键接口**：
```typescript
interface AgentCommunityService {
  // Bot 管理
  createBot(input: CreateBotRequest): Promise<BotIdentity>
  updateBot(input: UpdateBotRequest): Promise<BotIdentity>
  deleteBot(input: DeleteBotRequest): Promise<void>
  listBots(): Promise<BotIdentity[]>
  
  // 房间管理
  createRoom(input: CreateRoomRequest): Promise<BotRoom>
  updateRoom(input: UpdateRoomRequest): Promise<BotRoom>
  deleteRoom(input: DeleteRoomRequest): Promise<void>
  listRooms(): Promise<BotRoom[]>
  
  // 消息管理
  sendMessage(input: SendRoomMessageRequest): Promise<BotMessage>
  listMessages(roomId: BotRoomId): Promise<BotMessage[]>
  
  // 运行管理
  listRuns(botId?: BotId): Promise<BotRun[]>
  retryRun(input: RetryBotRunRequest): Promise<BotRun>
  controlRun(input: ControlBotRunRequest): Promise<BotRun>
}
```

**数据持久化**：
- 存储路径：`~/.dsh/agent-community/state.json`
- 格式：JSON with atomic write
- 包含：bots, rooms, messages, runs, mailbox

### 3.2 agent-team 包

**功能职责**：
- 团队成员管理（Roster）
- 任务管理（Task Board）
- 成员间消息传递（Mailbox）
- 团队生命周期（Lifecycle）

**核心服务**：`TeamService`

**关键接口**：
```typescript
interface TeamService {
  // 成员管理
  spawnTeammate(caller: Agent, request: SpawnTeammateRequest): Promise<SpawnTeammateResult>
  listMembers(agent: Agent): TeamMemberView[]
  membership(agent: Agent): TeamMembership
  
  // 消息传递
  sendMessage(caller: Agent, request: SendTeamMessageRequest): Promise<SendTeamMessageResult>
  
  // 任务管理
  createTask(caller: Agent, request: CreateTeamTaskRequest): Promise<TeamTaskView>
  getTask(caller: Agent, id: TeamTaskId): TeamTaskView
  listTasks(caller: Agent): TeamTaskView[]
  updateTask(caller: Agent, request: UpdateTeamTaskRequest): Promise<TeamTaskView>
}
```

**数据持久化**：
- 基于 Lead Session 日志的投影（Projection）
- 通过 `sessionProjections.register()` 注册
- 数据写入 Lead Session 持久化层

## 五、技术实现细节

### 5.1 数据持久化策略

#### Agent Community 持久化

**存储结构**：
```json
{
  "version": 2,
  "bots": [...],
  "rooms": [...],
  "messages": [...],
  "runs": [...],
  "mailbox": [...],
  "roomAgentSessions": [...]
}
```

**存储位置**：`~/.dsh/agent-community/state.json`

**写入策略**：
- 使用 atomic write 保证原子性
- 通过文件锁防止并发冲突
- 序列化操作队列保证一致性

#### Agent Team 持久化

**存储方式**：基于 Session 日志投影

**关键机制**：
- 通过 `sessionProjections.register()` 注册投影定义
- 所有团队数据写入 Lead Session 的持久化层
- 通过投影查询实时重建团队状态

**优势**：
- 无需额外存储文件
- 天然支持跨会话恢复
- 与 DSH Session 系统深度集成

### 5.2 消息路由机制

#### 社区消息路由

```typescript
// 消息发送流程
用户消息 -> Room
  -> 根据 policy 选择 Bot（round-robin / mention-only）
  -> 创建 BotRun
  -> 调度执行
  -> Bot 回复 -> 保存到消息历史
```

**调度策略**：
- Round-robin: 轮流响应
- Mention-only: 仅响应 @提及
- Direct: 直接聊天单对单

#### 团队消息路由

```typescript
// 团队消息传递
Sender -> TeamMailbox.send()
  -> 入队 pending message
  -> 尝试立即投递到 receiver Session
  -> 如果失败则等待 receiver 主动拉取
  -> 标记为 settled
```

**邮箱机制**：
- 持久化消息队列
- 支持跨 Session 传递
- 确保消息不丢失

### 5.3 工具权限和安全

**权限检查**：
```typescript
// 团队操作权限验证
membership(agent: Agent): TeamMembership {
  // 验证 agent 是否属于团队
  // 返回角色（lead / teammate）
  // 只有团队成员可以调用团队工具
}
```

**安全措施**：
1. 所有工具调用必须传入 `Agent` 实例
2. 通过 `Agent.session` 验证身份
3. 团队操作限制在团队成员范围
4. Bot 只能访问自己的会话和房间

### 5.4 UI 与 Host 通信

**Remote API 模式**：
```typescript
// 前端调用
const result = await ctx.remoteCall('agentCommunity.createBot', {
  name: 'MyBot',
  systemPrompt: '...'
})

// Host 端处理
ctx.provide('remoteApi', {
  'agentCommunity.createBot': async (input) => {
    return ctx.agentCommunity.createBot(input)
  }
})
```

**状态订阅**：
- 使用 EventEmitter 推送状态变更
- 前端订阅感兴趣的事件
- 实时更新 UI 显示
