## Overview

Connections to Model Context Protocol tools and resources. This page indexes the packages retained by the Aeoth Desktop runtime.

## Packages

- [`@deepseek-ai/dsh-mcp-client`](mcp-client/README.md) — MCP client bridge: connects to MCP servers and registers their tools on ctx.tools
- [`@deepseek-ai/dsh-mcp-resources`](mcp-resources/README.md) — Scoped MCP resource discovery and reading through shared model tools
