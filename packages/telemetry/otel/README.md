# @deepseek-ai/dsh-otel

English | [中文](README.zh.md)

This package is part of the Aeoth Desktop runtime. Electron and the application-owned Host are the product entry points; this README documents the package contract.


Provide separate OTLP channels for ordinary product events and size-bounded Session logs. Business plugins decide what is eligible to send; this service owns buffering and transport.
