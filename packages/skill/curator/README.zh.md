# @deepseek-ai/dsh-skill-curator

Curator 管理模型生成的技能候选：模型只能提交 `skill_propose`，候选在用户批准前不会写入可发现的 profile 技能。设置页支持批准、拒绝、归档和恢复；批准写入原子 `SKILL.md`，归档只删除 Curator 管理的活动文件，候选正文仍保留以便恢复。

候选记录可带来源会话、工作区和理由，设置页可以打开来源会话并比较候选指令与当前文件。实际 `skill` 加载只按版本记录使用事件；成功/失败必须来自明确结果证据或用户反馈，反馈按会话事件和版本去重。名称、控制字符、疑似凭据、大小、符号链接和非法状态迁移都会被拒绝。

`/learn` 负责把来源或工作流交给模型检查并提交候选，不代表技能已生成、激活或验证。完整技能指令仍通过已有 `skill` 工具按需加载，不在提交时静默注入提示词。
